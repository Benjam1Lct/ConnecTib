## Sujet du Projet

Cette application web a été développée avec **CodeIgniter 4** et a pour objectif de proposer une plateforme de **vente en ligne** spécialisée dans les produits sportifs. Le produit phare est un **protège-tibia connecté**, accompagné d'autres articles de sport innovants et performants.

---

## Fonctionnalités Principales

- **Catalogue de produits** : Parcourez une sélection d'articles sportifs, avec des descriptions détaillées.
- **Système de commande** : Gérez facilement vos achats grâce à une interface intuitive.
- **Connexion utilisateur** : Créez un compte pour suivre vos commandes et accéder à des fonctionnalités personnalisées.
- **Paiement sécurisé** : Paiements en ligne rapides et protégés.
